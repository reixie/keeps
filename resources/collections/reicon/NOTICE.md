# Reicon collection icons

The SVGs use the Outline paths from the [Reicon source dataset](https://github.com/dqev/reicon/blob/ac1c3a828b0af57e1443b171ec932b9bb30f8cf8/data/icon-data.json), wrapped in standalone 24 × 24 SVGs. `archive.svg` uses `ui/archive-box` and `lightbulb.svg` uses `devices/bulb` to match Keeps' existing collection keys. The other files use the upstream icon names.

Reicon credits [Solar Icons by 480 Design](https://solar-icons.vercel.app/) ([CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)) and [Zappicon](https://zappicon.com/) as sources for its base icons. See the [upstream credits](https://github.com/dqev/reicon/blob/ac1c3a828b0af57e1443b171ec932b9bb30f8cf8/README.md#credits) and the [Reicon license](LICENSE).
