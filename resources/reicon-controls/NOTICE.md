# Reicon controls

These icons use Outline paths from the [pinned Reicon dataset](https://github.com/dqev/reicon/blob/ac1c3a828b0af57e1443b171ec932b9bb30f8cf8/data/icon-data.json). The paths are wrapped as standalone SVGs. The PNGs are 32-pixel template images rendered from the same paths.

The Reicon base icons credit [Solar Icons by 480 Design](https://solar-icons.vercel.app/) ([CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)) and [Zappicon](https://zappicon.com/). See the [upstream credits](https://github.com/dqev/reicon/blob/ac1c3a828b0af57e1443b171ec932b9bb30f8cf8/README.md#credits) and [license](LICENSE).
